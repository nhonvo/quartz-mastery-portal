# 05. Conditional for Estimations

## Part 1: Resource Lesson (Deep Dive Theory)

### 🎯 Executive Summary & Objectives
**Goal**: Use the *Conditional* tense to provide professional software estimations, discuss hypothetical scenarios, and soften requests.

**Engineering Impact**: Prevents you from making hard commitments that you cannot keep. The conditional tense shifts your language from absolute guarantees ("I will finish it") to professional projections ("It would take", "It could be"), safeguarding your credibility in agile estimations.

### ⚙️ Contrastive Analysis & Theory
- **Future Tense**: Firm commitment. (e.g., Lo **terminaré** mañana - I *will* finish it tomorrow).
- **Conditional Tense**: Estimation, polite request, or hypothetical. Formed by adding -ía to the infinitive (e.g., terminar -> terminaría).
  - *Example*: **Tomaría** unas tres semanas. (It *would* take about three weeks).
  - *Polite Request*: ¿**Podrías** revisar este PR? (Could you review this PR?).

**Bilingual Context (EN/ES/VN)**: 
*EN*: "Refactoring this **would take** 2 sprint points." 
*ES*: "Refactorizar esto **tomaría** 2 puntos de sprint."
*VN*: "Việc tái cấu trúc phần này **sẽ mất khoảng** (would take) 2 story points."

### 🛠️ Real-World Engineering Context Comparison
- **Junior (B1)**: Yo termino esto en dos días. (Overly confident, risky).
- **Senior (C1/C2)**: Asumiendo que no hay bloqueos, **estimaría** que la implementación **requeriría** unos dos días. (Assuming no blockers, I would estimate the implementation would require about two days).
- **LATAM vs Spain Lexical Callout**:
  - *Spain*: ¿**Podríais** (vosotros) echarle un vistazo a mi código? (Could you guys take a look at my code?).
  - *LATAM*: ¿**Podrían** (ustedes) revisar mi código? (Could you guys review my code?).

### 🎭 Role-Play Dialogue (Backlog Grooming)
**Product Owner (Laura)**: ¿Cuánto tiempo **tomaría** (conditional) integrar la nueva pasarela de pagos? (How long would it take to integrate the new payment gateway? / Sẽ mất bao lâu để tích hợp cổng thanh toán mới?)

**Lead Dev (Roberto)**: Bueno, si la API de ellos es estable, yo **diría** (conditional) que nos **llevaría** (conditional) un sprint entero. (Well, if their API is stable, I would say it would take us a whole sprint. / Chà, nếu API của họ ổn định, tôi có thể nói rằng chúng ta sẽ mất cả một sprint.)

**Product Owner (Laura)**: Perfecto. ¿**Podrías** (conditional) crear las sub-tareas para mañana? (Perfect. Could you create the sub-tasks for tomorrow? / Hoàn hảo. Bạn có thể tạo các sub-tasks (nhiệm vụ phụ) vào ngày mai không?)

### 📚 Bilingual Technical Vocabulary
| Español (ES) | English (EN) | Tiếng Việt (VN) |
| :--- | :--- | :--- |
| Tomaría / Llevaría | It would take | Sẽ mất (thời gian) |
| Yo diría que... | I would say that... | Tôi sẽ nói rằng... / Theo tôi... |
| Podrías / Podrían | Could you (sing/pl) | Bạn/Các bạn có thể... không? |
| Estimaría | I would estimate | Tôi ước tính (sẽ) |
| Requeriría | It would require | Sẽ yêu cầu / cần |

### 🚫 Common Anti-Patterns
- ❌ *Toma 5 días.* (Present tense, stated as a hard fact).
- ✅ *Tomaría 5 días.* (Conditional, allowing room for unknowns).
- ❌ *Puedes ayudarme?* (A bit direct for asking favors from a busy senior).
- ✅ *¿Podrías ayudarme?* (Softer, more professional).

## Part 3: Assessment Exam

### ❓ MCQs
1. "I would estimate that this is a 5-point story."
   - [ ] A. Yo estimo que...
   - [ ] B. Yo estimaré que...
   - [ ] C. Yo estimaría que...
   *Answer: c*
2. "Could you review my Pull Request?"
   - [ ] A. ¿Puedes revisar mi PR? (Grammatically correct but less polite)
   - [ ] B. ¿Podrías revisar mi PR?
   - [ ] C. ¿Podrás revisar mi PR?
   *Answer: b (Podrías is the polite conditional)*
3. "The query would run faster with an index."
   - [ ] A. La consulta correrá más rápido...
   - [ ] B. La consulta correría más rápido...
   - [ ] C. La consulta corre más rápido...
   *Answer: b*
4. "I would like to propose a new architecture."
   - [ ] A. Me gustaba proponer...
   - [ ] B. Me gustaré proponer...
   - [ ] C. Me gustaría proponer...
   *Answer: c*
5. "In a perfect world, we would rewrite the whole app."
   - [ ] A. reescribíamos
   - [ ] B. reescribiremos
   - [ ] C. reescribiríamos
   *Answer: c*

### 🧪 Fill-in-the-Blanks
1. Yo ________ (decir) que necesitamos más memoria en ese nodo.
2. ¿Te ________ (importar) revisar este log conmigo?
3. Sin la caché, el sistema ________ (colapsar) bajo esta carga.
4. Nosotros ________ (preferir) usar PostgreSQL en lugar de MySQL.
5. El proceso de despliegue nos ________ (llevar) unas tres horas.
*(Answers: 1. diría, 2. importaría, 3. colapsaría, 4. preferiríamos, 5. llevaría)*

### 🔍 Error Refactoring
Rewrite to C1 level using conditional tense:
1. *Junior*: Esto toma 3 días.
   - *Refactored*: Bajo condiciones normales, esto **tomaría** 3 días.
2. *Junior*: Ayúdame con este bug, por favor.
   - *Refactored*: ¿**Podrías** apoyarme investigando este bug, por favor?
3. *Junior*: Quiero implementar gRPC aquí.
   - *Refactored*: Me **gustaría** sugerir la implementación de gRPC en este servicio.
4. *Junior*: El frontend necesita refactorización gruesa.
   - *Refactored*: Yo **diría** que el frontend **requeriría** una refactorización sustancial.
5. *Junior*: Si quitamos la caché, la base de datos muere.
   - *Refactored*: Si elimináramos la caché, la base de datos **sufriría/colapsaría** bajo la carga.
