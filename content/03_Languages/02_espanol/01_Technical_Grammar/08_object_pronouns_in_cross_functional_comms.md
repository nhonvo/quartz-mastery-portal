# 08. Object Pronouns in Cross-Functional Comms

## Part 1: Resource Lesson (Deep Dive Theory)

### 🎯 Executive Summary & Objectives
**Goal**: Master Direct (lo, la, los, las) and Indirect (le, les, se) Object Pronouns for efficient, concise communication across teams.
**Engineering Impact**: Repetitive noun usage ("I sent the report to the manager, the manager read the report") sounds very unnatural. C1/C2 proficiency requires pronoun chaining ("Se lo envié") to keep stand-ups and slack threads concise and fluid.

### ⚙️ Contrastive Analysis & Theory
- **Direct Object (DO)**: Answers "What?" or "Who?" receives the action directly. 
  - *Pronouns*: lo, la, los, las. 
  - *Example*: Terminé el ticket -> **Lo** terminé. (I finished it).
- **Indirect Object (IO)**: Answers "To whom?" or "For whom?" the action is done.
  - *Pronouns*: me, te, le, nos, les. 
  - *Example*: Escribí un correo a la PM -> **Le** escribí un correo. (I wrote her an email).
- **Double Object Pronouns**: IO comes before DO. Rule: "Le lo" becomes "Se lo".
  - *Example*: Envié el reporte (DO) al equipo (IO) -> **Se lo** envié. (I sent it to them).

**Bilingual Context (EN/ES/VN)**: 
*EN*: "Did you send the API key to QA? Yes, I sent **it** to **them**." 
*ES*: "¿Le enviaste la API key a QA? Sí, **se la** envié." (se = to them, la = it/API key).
*VN*: "Bạn đã gửi API key cho QA chưa? Rồi, tôi đã gửi **nó** cho **họ**." (Vietnamese keeps explicit words 'nó' and 'họ', Spanish compresses them into 'se la' before the verb).

### 🛠️ Real-World Engineering Context Comparison
- **Junior (B1)**: Yo envié el pull request a ti. (Too wordy, unnatural).
- **Senior (C1/C2)**: Ya **te lo** envié por Slack. (I already sent it to you via Slack. Fluid and native).
- **LATAM vs Spain Lexical Callout (Leísmo)**:
  - *Spain*: Al cliente, **le** vi ayer. (Spain often uses 'le' for direct object males - Leísmo).
  - *LATAM*: Al cliente, **lo** vi ayer. (Strict adherence to standard DO pronouns).

### 🎭 Role-Play Dialogue (Daily Stand-up)
**Scrum Master (Diego)**: Carlos, ¿ya actualizaste el pipeline de CI/CD? (Carlos, did you update the CI/CD pipeline yet? / Carlos, bạn đã cập nhật pipeline CI/CD chưa?)
**Dev (Carlos)**: Sí, **lo** actualicé anoche y **les** mandé un mensaje a los QA. (Yes, I updated it last night and sent a message to the QAs. / Vâng, tôi đã cập nhật nó tối qua và gửi tin nhắn cho các bạn QA.)
**Scrum Master (Diego)**: Perfecto. ¿Y el documento de arquitectura? (Perfect. What about the architecture doc? / Hoàn hảo. Còn tài liệu kiến trúc thì sao?)
**Dev (Carlos)**: **Se lo** compartí a la Tech Lead hace una hora. (I shared it with the Tech Lead an hour ago. / Tôi đã chia sẻ nó với Tech Lead cách đây một giờ.)

### 📚 Bilingual Technical Vocabulary
| Español (ES) | English (EN) | Tiếng Việt (VN) |
| :--- | :--- | :--- |
| Lo actualicé | I updated it | Tôi đã cập nhật nó |
| Le envié | I sent (to) him/her | Tôi đã gửi cho anh ấy/cô ấy |
| Se lo compartí | I shared it with them/him | Tôi đã chia sẻ nó với họ/anh ấy |
| Te lo explico | I'll explain it to you | Tôi sẽ giải thích nó cho bạn |
| Las desplegamos | We deployed them (e.g. apps) | Chúng tôi đã triển khai chúng |

### 🚫 Common Anti-Patterns
- ❌ *Yo le envié lo.* (Object pronouns MUST go before the conjugated verb).
- ✅ *Yo se lo envié.* (Correct order: IO + DO + Verb).
- ❌ *Le lo envié.* (Le turns into Se when next to lo/la).

## Part 3: Assessment Exam

### ❓ MCQs
1. "Did you fix the bug?" -> "Sí, ____ arreglé."
   - [ ] A. lo
   - [ ] B. le
   - [ ] C. me
   *Answer: a (el bug is masculine direct object)*
2. "I sent the logs to Maria." -> "____ envié los logs."
   - [ ] A. La
   - [ ] B. Lo
   - [ ] C. Le
   *Answer: c (Indirect object for Maria is le)*
3. "I explained the architecture (to them)." -> "____ expliqué la arquitectura."
   - [ ] A. Los
   - [ ] B. Les
   - [ ] C. Las
   *Answer: b (Les for 'to them')*
4. "I showed the code (el código) to the client (al cliente)." -> "____ mostré."
   - [ ] A. Se lo
   - [ ] B. Le lo
   - [ ] C. Lo le
   *Answer: a*
5. "Can you send the credentials to me?" -> "¿____ puedes enviar las credenciales?"
   - [ ] A. Te
   - [ ] B. Se
   - [ ] C. Me
   *Answer: c*

### 🔍 Error Refactoring
Rewrite these clunky sentences to fluid C1 level using pronouns:
1. *Junior*: Escribí el código y mandé el código a QA.
   - *Refactored*: Escribí el código y **se lo** mandé a QA.
2. *Junior*: Yo di los permisos al usuario nuevo.
   - *Refactored*: Yo **le** di los permisos al usuario nuevo. (Or: **Se los** di).
3. *Junior*: ¿Tú puedes revisar la PR para mí?
   - *Refactored*: ¿**Me** puedes revisar la PR? / ¿Puedes revisár**me**la?
4. *Junior*: Yo no tengo la contraseña, el dev no dio la contraseña a mí.
   - *Refactored*: No tengo la contraseña, el dev no **me la** dio.
5. *Junior*: Informé a los stakeholders del incidente.
   - *Refactored*: **Les** informé del incidente a los stakeholders.
