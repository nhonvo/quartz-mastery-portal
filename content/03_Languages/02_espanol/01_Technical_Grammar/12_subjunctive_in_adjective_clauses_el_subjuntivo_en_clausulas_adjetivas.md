# 12. Subjunctive in Adjective Clauses (El Subjuntivo en Cláusulas Adjetivas)

## Part 1: Resource Lesson (Deep Dive Theory)

### 🎯 Executive Summary & Objectives
**Goal**: Master the use of the subjunctive mood in adjective clauses to describe unknown, hypothetical, or non-existent technologies, candidates, or solutions.

**Engineering Impact**: Engineers constantly design systems for future requirements or search for tools that fulfill specific criteria (e.g., "We need a database that *supports* ACID"). Using the subjunctive accurately signals whether you are talking about a specific, existing tool or a hypothetical requirement, crucial for clear technical specifications and architecture planning.

### ⚙️ Contrastive Analysis & Theory
Adjective clauses describe a noun (the antecedent). The choice between **Indicative** and **Subjunctive** depends on whether the antecedent is known/specific or unknown/indefinite/non-existent.

1. **Indicative**: Used when the antecedent is a specific, known, existing entity.
   - *Tenemos una base de datos que **escala** bien.* (We have a database that scales well. - We know which one it is, it exists.)
2. **Subjunctive**: Used when the antecedent is unknown, hypothetical, or doesn't exist.
   - *Buscamos una base de datos que **escale** bien.* (We are looking for a database that scales well. - We haven't found it yet; it's a requirement.)
   - *No hay ninguna herramienta que **haga** esto.* (There is no tool that does this. - Non-existent.)

### 🎭 Role-Play Dialogue (Spain Tech Workplace)
**Context**: Architecture planning meeting between a Tech Lead (Javier) and a DevOps Engineer (Lucía).

**Javier**: Lucía, necesitamos una herramienta de monitorización que nos **alerte** (subjunctive of *alertar*) cuando la CPU supere el 80%.
*(Lucía, we need a monitoring tool that alerts us when the CPU exceeds 80%.)*
*(Lucía, chúng ta cần một công cụ monitoring có thể cảnh báo chúng ta khi CPU vượt quá 80%.)*

**Lucía**: Vale. Conozco un par de opciones, pero no hay ninguna que se **integre** (subjunctive of *integrar*) perfectamente con nuestro orquestador actual sin desarrollo a medida.
*(Okay. I know a couple of options, but there isn't any that integrates perfectly with our current orchestrator without custom development.)*
*(Ok. Tôi biết một vài tùy chọn, nhưng không có cái nào tích hợp hoàn hảo với orchestrator hiện tại của chúng ta mà không cần dev thêm.)*

**Javier**: Entendido. Entonces, busquemos algo que **ofrezca** (subjunctive of *ofrecer*) una API abierta, y nosotros construiremos la integración. ¿Conoces alguna que **tenga** (subjunctive of *tener*) SDK en Python?
*(Understood. Then, let's look for something that offers an open API, and we will build the integration. Do you know any that has a Python SDK?)*
*(Đã hiểu. Vậy hãy tìm một cái gì đó cung cấp API mở, và chúng ta sẽ tự xây dựng phần tích hợp. Bạn có biết cái nào có Python SDK không?)*

### 🚫 Common Anti-Patterns
- **Mistake**: *Quiero diseñar un sistema que es tolerante a fallos.* (Using indicative for a planned/hypothetical system).
- **Correction**: *Quiero diseñar un sistema que **sea** tolerante a fallos.*
- **Why**: The system doesn't exist yet; it's a requirement/goal, requiring the subjunctive.

## Part 2: Practice Workspace

### Scenario & Context
You are writing a job description for a new Data Engineer position. You need to outline the requirements for a hypothetical ideal candidate (using the subjunctive because the person hasn't been hired yet). They must know Apache Spark, have experience with AWS, and be able to optimize data pipelines.

### User Practice Area
*(Write your response in Spanish here...)*

### Progressive Socratic Hints
1. **Hint 1**: Start with "Buscamos un Ingeniero de Datos que..." (We are looking for a Data Engineer who...).
2. **Hint 2**: Use the subjunctive of *conocer* (to know/be familiar with) for Apache Spark.
3. **Hint 3**: Use the subjunctive of *tener* (to have) for experience in AWS, and *poder* (to be able to) for optimizing pipelines.
