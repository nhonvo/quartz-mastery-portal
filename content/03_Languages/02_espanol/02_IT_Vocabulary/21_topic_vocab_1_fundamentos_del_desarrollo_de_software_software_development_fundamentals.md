# 🚀 Topic Vocab 1: Fundamentos del Desarrollo de Software (Software Development Fundamentals)

## Part 1: Resource Lesson (Deep Dive Theory)

### 🎯 Executive Summary & Objectives
**Goal**: Master foundational software development vocabulary in Spanish, bridging the gap between English-centric tech jargon and correct professional Spanish. 

**Engineering Impact**: Effectively discuss code structure, variables, algorithms, and logic with LATAM or Spanish teams without constantly reverting to "Spanglish".

### ⚙️ Contrastive Analysis & Theory
In Spanish, many tech terms are adapted from English, but DELE standards and formal documentation require specific translations. 
- *Code* -> *Código*
- *Bug* -> *Error* or *Fallo* (Though *bug* is widely used, formal contexts prefer *error*).
- *Feature* -> *Característica* or *Funcionalidad*.

**🌍 Regional Variations (LATAM vs. Spain):**
- **Computer:** *Computadora* (LATAM) vs. *Ordenador* (Spain).
- **To click:** *Dar clic* (LATAM) vs. *Clicar / Pinchar* (Spain).
- **Bug:** *Fallo / Incidencia* (Spain) are preferred in formal writing, whereas LATAM tech culture often adopts *bug* and *bugueado* (bugged) more fluidly.

### 🛠️ Real-World Engineering Context Comparison
- **Junior (B1)**: "El código tiene un bug en esta feature."
- **Mid-Level (B2)**: "Hay un error en esta funcionalidad; el código fuente no compila."
- **Senior (C1/C2 Executive)**: "Hemos detectado una anomalía crítica en la lógica central del componente, la cual compromete la funcionalidad principal. Procederemos a depurar exhaustivamente el código base para garantizar la estabilidad del despliegue en producción."

### 🎭 Role-Play Dialogue
**Contexto:** LATAM Tech Startup - Revisión de código matutina.
**Juan (Senior):** Oye, revisé tu *pull request* (solicitud de extracción). Hay un problema de rendimiento en el algoritmo principal. *(VN: Này, tôi đã xem xét pull request của bạn. Có một vấn đề về hiệu suất trong thuật toán chính.)*
**Ana (Junior):** Ah, ¿te refieres al bucle infinito? Pensé que la condición de salida estaba clara. *(VN: À, ý bạn là vòng lặp vô hạn sao? Tôi tưởng điều kiện thoát đã rõ ràng.)*
**Juan:** No, la *variable de entorno* (environment variable) no se está inyectando correctamente, lo que causa que el *flujo de control* (control flow) falle. *(VN: Không, biến môi trường không được tiêm vào đúng cách, dẫn đến việc luồng điều khiển bị lỗi.)*

### 📚 Bilingual Technical Vocabulary
| Español | English | Tiếng Việt | Context/Usage |
| :--- | :--- | :--- | :--- |
| Código fuente | Source code | Mã nguồn | Base de un programa |
| Depurar | To debug | Gỡ lỗi | Encontrar y corregir errores |
| Despliegue | Deployment | Triển khai | Subir a producción |
| Entorno de desarrollo | Development environment | Môi trường dev | Donde se escribe el código |
| Rendimiento | Performance | Hiệu suất | Velocidad/eficiencia del sistema |
| Funcionalidad | Feature | Tính năng | Capacidad del software |

### 🚫 Common Anti-Patterns
- ❌ "Hacer deploy" -> ✅ "Desplegar" o "Realizar el despliegue".
- ❌ "El code" -> ✅ "El código".
