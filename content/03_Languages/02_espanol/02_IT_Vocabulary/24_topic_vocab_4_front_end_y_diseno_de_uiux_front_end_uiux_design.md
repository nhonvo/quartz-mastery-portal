# 🚀 Topic Vocab 4: Front-end y Diseño de UI/UX (Front-end & UI/UX Design)

## Part 1: Resource Lesson (Deep Dive Theory)

### 🎯 Executive Summary & Objectives
**Goal**: Communicate fluidly about user interfaces, user experience, layout, state management, and responsive design.

**Engineering Impact**: Ensuring designers and front-end engineers are on the same page regarding margins, components, accessibility, and state.

### ⚙️ Contrastive Analysis & Theory
- *Responsive design* -> *Diseño responsivo* o *Diseño adaptable*.
- *State* -> *Estado*.
- *Component* -> *Componente*.
- *Accessibility* -> *Accesibilidad* (a11y).

**🌍 Regional Variations (LATAM vs. Spain):**
- **Layout/Mockup:** Spain uses *maquetación* and *boceto*, whereas LATAM engineers frequently adopt *layout* and *mockup* directly, or use *diseño visual*.
- **Responsive:** *Diseño adaptativo/adaptable* is preferred in Spain's formal UI guidelines, while *responsivo* is a direct calque highly prevalent in LATAM.

### 🛠️ Real-World Engineering Context Comparison
- **Junior (B1)**: "El botón está feo en los móviles y no hace nada al hacer clic."
- **Mid-Level (B2)**: "El componente no es responsivo y el estado no se actualiza correctamente."
- **Senior (C1/C2 Executive)**: "El componente interactivo carece de un diseño adaptable robusto y falla al sincronizar el estado global mediante el flujo unidireccional. Además, debemos garantizar que el árbol de accesibilidad (a11y) exponga el rol semántico adecuado."

### 📚 Bilingual Technical Vocabulary
| Español | English | Tiếng Việt | Context/Usage |
| :--- | :--- | :--- | :--- |
| Diseño adaptable | Responsive design | Thiết kế đáp ứng | UI que se adapta a pantallas |
| Interfaz de usuario (IU) | User Interface (UI) | Giao diện người dùng | Lo que el usuario ve |
| Estado | State | Trạng thái | Datos de la aplicación |
| Componente | Component | Thành phần | Parte reutilizable de la UI |
| Accesibilidad | Accessibility | Khả năng truy cập | Usable por todos (incluyendo discapacitados) |
| Esquema de página | Wireframe | Khung trang | Boceto de diseño |

### 🚫 Common Anti-Patterns
- ❌ "Diseño responsive" -> ✅ "Diseño responsivo" / "Diseño adaptable".
- ❌ "El state de React" -> ✅ "El estado de React".
