# 🚀 Topic Vocab 2: Computación en la Nube e Infraestructura (Cloud Computing & Infrastructure)

## Part 1: Resource Lesson (Deep Dive Theory)

### 🎯 Executive Summary & Objectives
**Goal**: Acquire advanced vocabulary for discussing cloud architecture, servers, and infrastructure scalability.
**Engineering Impact**: Architecting systems on AWS/GCP/Azure with Hispanic teams requires precise terms for load balancing, instances, and availability zones.

### ⚙️ Contrastive Analysis & Theory
- *Cloud computing* -> *Computación en la nube*.
- *Scalability* -> *Escalabilidad* (capacidad de crecer).
- *Serverless* -> *Sin servidor* (aunque "serverless" se usa mucho, "arquitectura sin servidor" es más formal).

**🌍 Regional Variations (LATAM vs. Spain):**
- **Cloud/Datacenter:** Both regions use *la nube*. In Spain, *Centro de Datos* is rigorously used in formal writing, whereas LATAM engineers might interchangeably say *Data Center*.
- **To crash (server):** *Caerse* (El servidor se cayó) is universally understood. However, in LATAM, *crashear* is widely adapted in spoken tech environments. In Spain, *petar* is a common colloquialism, but *sufrir una caída* or *interrupción del servicio* is strictly preferred for C1/C2 formal reports.

### 🛠️ Real-World Engineering Context Comparison
- **Junior (B1)**: "El servidor se cayó porque había mucho tráfico."
- **Mid-Level (B2)**: "La base de datos se sobrecargó; necesitamos configurar un balanceador de carga."
- **Senior (C1/C2 Executive)**: "La instancia experimentó una sobrecarga crítica de peticiones; la falta de un balanceador de carga adecuado y autoescalado dinámico comprometió gravemente la alta disponibilidad del sistema. Procederemos a rediseñar la topología de red."

### 📚 Bilingual Technical Vocabulary
| Español | English | Tiếng Việt | Context/Usage |
| :--- | :--- | :--- | :--- |
| Nube pública/privada | Public/private cloud | Đám mây công cộng/riêng | Tipos de nube |
| Escalabilidad | Scalability | Khả năng mở rộng | Crecer según la demanda |
| Balanceador de carga | Load balancer | Bộ cân bằng tải | Distribuye el tráfico |
| Aprovisionar | To provision | Cung cấp / Cấp phát | Crear recursos en la nube |
| Latencia | Latency | Độ trễ | Tiempo de respuesta |
| Máquina virtual (MV) | Virtual Machine (VM) | Máy ảo | Servidor emulado |

### 🚫 Common Anti-Patterns
- ❌ "El server crashó" -> ✅ "El servidor se cayó" o "Hubo una caída del servidor".
- ❌ "Escalabilidad horizontal es más barata" -> ✅ "El escalado horizontal es más económico".
