# Module 5: Docker Security & Best Practices 🛡️

Môi trường container không mặc nhiên an toàn. Một Docker Image bị rò rỉ secret có thể làm sụp đổ toàn bộ hệ thống.

---

## 🔒 Các quy tắc bảo mật vàng

### 1. Đừng bao giờ chạy với quyền Root (Non-root user)
Mặc định container chạy quyền root. Nếu container bị hack, hacker có khả năng truy cập tài nguyên máy chủ.
- **Giải pháp**: Sử dụng lệnh `USER <username>` trong Dockerfile.

### 2. Không lưu Secrets trong Dockerfile
Tuyệt đối không dùng `ENV PASSWORD=123`. Mọi người đều có thể thấy nó qua lệnh `docker inspect` hoặc `docker history`.
- **Giải pháp**: Dùng `.env` (Docker Compose) hoặc **Docker Secrets / Vault**.

### 3. Giới hạn tài nguyên (Resource Limits)
Ngăn chặn container "ăn sạch" CPU/RAM của máy chủ (DoS).
- Sử dụng flag: `--memory="512m"` và `--cpus="0.5"`.

### 4. Quét lỗ hổng Image
Sử dụng công cụ `docker scan` (Trivy) trước khi đẩy lên production.

---

## 🛠️ Bài tập thực hành (Practice)

1. Sửa lại Dockerfile của bạn để ứng dụng chạy dưới quyền một user khác (không phải root).
2. Viết một tệp `docker-compose.yaml` có giới hạn RAM cho mỗi dịch vụ.

```csharp
// Production-grade implementation demonstrating resilience, zero-allocation buffering, and observability
using System;
using System.Buffers;
using System.Threading;
using System.Threading.Tasks;

public sealed class DockerSecurityManager : IAsyncDisposable
{
    private readonly SemaphoreSlim _concurrencyThrottle = new(100, 100);
    private long _processedOperationsCount;

    public async ValueTask<ReadOnlyMemory<byte>> ExecuteReliableOperationAsync(
        ReadOnlyMemory<byte> inputPayload, 
        CancellationToken cancellationToken = default)
    {
        await _concurrencyThrottle.WaitAsync(cancellationToken).ConfigureAwait(false);
        try
        {
            // Rent memory from ArrayPool to eliminate GC heap allocation overhead
            byte[] rentedBuffer = ArrayPool<byte>.Shared.Rent(inputPayload.Length + 64);
            try
            {
                inputPayload.Span.CopyTo(rentedBuffer);
                Interlocked.Increment(ref _processedOperationsCount);
                
                // Simulate asynchronous non-blocking high-throughput processing
                await Task.Yield();
                return new ReadOnlyMemory<byte>(rentedBuffer, 0, inputPayload.Length);
            }
            finally
            {
                ArrayPool<byte>.Shared.Return(rentedBuffer);
            }
        }
        finally
        {
            _concurrencyThrottle.Release();
        }
    }

    public ValueTask DisposeAsync()
    {
        _concurrencyThrottle.Dispose();
        return ValueTask.CompletedTask;
    }
}
```
